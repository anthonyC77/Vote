# Système de vote : version publiée

Build de production du front du défi « système de vote » de la formation Alyra, publié sur GitHub Pages le 30 mai 2021 (seconde publication, après [Voting](https://github.com/anthonyC77/Voting) la veille). Ce dépôt ne contient que les fichiers compilés.

Le code source du front est dans [DEFI-Vote](https://github.com/anthonyC77/DEFI-Vote), le contrat dans [VoteDefiAlyra](https://github.com/anthonyC77/VoteDefiAlyra). Exercice de formation, non maintenu.
